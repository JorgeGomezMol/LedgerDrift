# Roadmap

## 0.1 (current)

- Canonical schema with column mapping
- Reconciliation mode for nine defect types
- Ledger-only detection with confidence levels
- Unsupervised review queue
- Synthetic data generator with defect injection and legitimate variation
- Aggregate summaries and discrepancy log

## 0.2

- Ready-made mappings for common PSA and accounting exports
- Per-line anomaly scoring for labor entries (engineer, project and day patterns)
- HTML report for non-technical reviewers
- Configurable thresholds through a settings file

## 0.3

- Detection of corrupted payment identifiers and processor batch mismatches
- Period-close checklist generated from findings
- Guidance for small accounting firms applying the method across client books

Priorities change with what real implementations find.
